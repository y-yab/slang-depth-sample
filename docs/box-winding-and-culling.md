# Box の頂点巻き順と Back-Face Culling (Slang + D3D12)

このメモは、Box が裏返って見えた原因、実施した修正、確認手順をまとめたものです。

## 症状

- カメラは Box の外側にある。
- それでも Box の内側が見えているように見える。

## 原因

面の表示・非表示は次の 2 つで決まります。

1. 三角形の巻き順 (インデックス順)
2. ラスタライザのカリング設定

巻き順と Front face 判定の規約が一致していないと、外側の面が Back face と判定されます。

## このプロジェクトでの主要設定

- 各 quad のインデックスを次に統一
  - 0, 1, 2
  - 0, 2, 3
- 各面の頂点 4 点は、上のインデックスで正しい面向きになる順に並べる
- パイプライン作成時に Back-face culling を有効化
  - desc.rasterizer.cullMode = rhi::CullMode::Back;

## 判定フロー

```mermaid
flowchart LR
    V[面ごとの頂点順] --> I[インデックス順: 0,1,2 / 0,2,3]
    I --> W[画面上の巻き方向]
    W --> F[Front / Back 判定]
    F --> C{CullMode}
    C -->|Back| D[Back face を破棄]
    C -->|None| R[両面を描画]
```

## 面構築ルール

各面 (4 頂点) を次の規則で並べます。

- v0: 基準コーナー
- v1: v0 から 1 辺進んだコーナー
- v2: 対角コーナー
- v3: 残りのコーナー

三角形は次の 2 つで構成します。

- t0 = (v0, v1, v2)
- t1 = (v0, v2, v3)

```mermaid
flowchart LR
  T0L[三角形 t0 = v0 -> v1 -> v2 -> v0]
  t0v0((v0)) --> t0v1((v1))
  t0v1 --> t0v2((v2))
  t0v2 --> t0v0
  T0L --- t0v0

  T1L[三角形 t1 = v0 -> v2 -> v3 -> v0]
  t1v0((v0)) --> t1v2((v2))
  t1v2 --> t1v3((v3))
  t1v3 --> t1v0
  T1L --- t1v0
```

2つの三角形は対角線 v0-v2 を共有し、合わせて 1 つの quad になります。

この形に統一すると、面ごとのインデックス例外が不要になります。

## デバッグ手順

メッシュが裏返って見えるときは次を確認します。

1. 一時的に CullMode::None にする。
2. 形が出るなら、巻き順と Front/Back 規約の不一致の可能性が高い。
3. CullMode::Back に戻す。
4. 面ごとに頂点順またはインデックス順を修正する。

## なぜ CullMode::Back を使うか

特定の視点では見た目が同じでも、CullMode::Back は有効にしておくのが基本です。

- 巻き順の不整合を早く発見できる
- オーバードローを減らせる
- 不透明描画の一般的な設定に一致する

## スクリーン空間フルスクリーンクアッドの巻き順

中間テクスチャを BackBuffer に貼り付けるフルスクリーンクアッドも同じ Back-face Culling が適用されます。
D3D12 のスクリーン空間は **Y 軸が下向き** であることに注意が必要です。

### 頂点定義

| インデックス | 位置 (NDC) | UV |
|---|---|---|
| 0 | (-1, +1, 0) TL | (0, 0) |
| 1 | (+1, +1, 0) TR | (1, 0) |
| 2 | (-1, -1, 0) BL | (0, 1) |
| 3 | (+1, -1, 0) BR | (1, 1) |

### 巻き順の比較

スクリーン空間の Y は下向きなので、数学の座標系と表裏の判定が逆になります。

| インデックス列 | 三角形 1 | 画面上の向き | 結果 |
|---|---|---|---|
| `0, 1, 2, 1, 3, 2` | TL → TR → BL | 時計回り (CW) = Back face | **カリングで破棄** |
| `0, 2, 1, 1, 2, 3` | TL → BL → TR | 反時計回り (CCW) = Front face | **描画される** |

### なぜ逆になるか

通常の数学座標系 (Y 上向き) では CCW が Front face ですが、スクリーン空間 (Y 下向き) では Y 座標の正負が反転するため、同じ頂点順でも巻き方向が逆になります。

```
数学座標系 (Y 上向き)          スクリーン空間 (Y 下向き)

  TL(0,1)  TR(1,1)              TL(0,0)  TR(1,0)
     0         1                   0         1
     +---------+                   +---------+
     |  CCW /  |                   |  CW  \  |
     |   /     |                   |      /  |
     +---------+                   +---------+
     2         3                   2         3
  BL(0,0)  BR(1,0)              BL(0,1)  BR(1,1)

 0→1→2 = CCW = Front ✓          0→1→2 = CW = Back ✗
```
